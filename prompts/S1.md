# S1 prompts

Author: Shriyans. Tool: Claude (Claude Code), with the assignment PDF and skills/scheme-dev/SKILL.md as instructions.

## Setup prompt (scheme-dev skill file)

```
I'm doing a university assignment in Racket 8.x (the PDF is attached to this
project). Before solving anything I need a skill file for you: a SKILL.md
that starts with a YAML header (name: scheme-dev, and a one-line
description), followed by instructions. Please include these sections:
1. Language and version: Racket 8.x, every file starts with #lang
racket/base, and the grader runs racket FILE.rkt after adding its own calls
to the end of the file.
2. The exact list of allowed built-ins from the PDF's "Scheme rules" section,
and a list of banned things (set! and relatives, vectors, hash tables,
strings, do/for loops, length, append, reverse, map, filter, member, memq,
list-ref, list-tail, and Racket-only names like first, rest, empty?, when,
unless, foldl, apply, printf). If a banned function is needed, write a helper
named my-something.
3. Coding conventions: kebab-case names, a comment above every function
giving its recursive reading (base case, recursive case), all state passed
through arguments, tail recursion with an accumulator where it is natural.
4. File rules: only definitions, no top-level calls, nothing printed when the
file loads, and every print function ends with (newline) so it returns
nothing that Racket would echo.
5. How to run and test: append a call to a copy of the file and run it with
racket, and a bash test script under tests/ that compares output to expected
output.
6. A self-review checklist you must go through before every answer, including
scanning the code for every banned name.
7. Known failure modes of AI tools in Scheme/Racket, for example: quietly
using length/append/reverse/map, using if without an else branch, using
Racket-only shortcuts, wrong handling of the empty list, deep non-tail
recursion, and printing extra text.
Also add a rule that you only do the one unit of work I ask for in each
message and never write a whole problem at once. Give me only the SKILL.md
content, in one code block.
```

## Prompt 1 (test script)

```
I'm starting problem S1 (binary tree traversals) from the PDF. Before writing
the solution, write a bash test script tests/test_q3.sh. The grader appends
its own calls to the end of my file, so for each test the script should: copy
code/1_q3.rkt to a temporary file, append the define of the tree and one
call, run it with racket, and compare the output with the expected output,
printing PASS or FAIL with the test name and a final count. Use every example
in the PDF: t1, t2, t3 and the empty tree, for print-inorder,
print-all-traversals and print-height-and-leaves. Add these extra cases of my own: a
single node (5 () ()) gives inorder (5), all three traversals (5), and
height-and-leaves (1 1); and a left-only chain (3 (2 (1 () ()) ()) ()) gives
inorder (1 2 3), preorder (3 2 1), postorder (1 2 3) and height-and-leaves (3
1). I'll run it from the repo root with: bash tests/test_q3.sh
```

## Prompt 2 (tree helpers)

```
S1, first unit of code: in 1_q3.rkt (starting with #lang racket/base) write
only small helper functions for the tree format in the PDF, where a tree is
() or (value left right): tree-value, tree-left, tree-right, empty-tree?, and
leaf? (a node whose left and right are both empty). Use only the allowed
built-ins (car, cadr, caddr, null? and so on). Nothing else yet.
```

## Prompt 3 (S1.a inorder and print-inorder)

```
S1.a: write a function that returns the inorder list of a tree (left subtree,
node, right subtree), without using append: pass an accumulator through the
recursion instead. Then write (print-inorder tree), which displays that list
on one line and ends with (newline). For the empty tree it should print ().
Explain the accumulator idea in plain words.
```

## Prompt 4 (preorder and postorder lists)

```
Next S1 unit: in the same accumulator style, write a function for the
preorder list (node, left, right) and one for the postorder list (left,
right, node). Still no append, reverse or other banned functions. Don't write
any print functions in this step.
```

## Prompt 5 (S1.b print-all-traversals)

```
S1.b: write (print-all-traversals tree). It prints three lines with display:
the inorder list, then the preorder list, then the postorder list, each
followed by a newline. Reuse the three list functions.
```
