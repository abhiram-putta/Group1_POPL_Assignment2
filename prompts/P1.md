# P1 prompts

## Prompt 1 (skill file)
I'm doing a university assignment in SWI-Prolog 9.x (the PDF is attached to
this project). Before solving anything I need a skill file for you: a
SKILL.md that starts with a YAML header (name: prolog-dev, and a one-line
description), followed by instructions. Please include these sections:
1. Language and version: SWI-Prolog 9.x, and how the grader runs files: swipl
-q -f FILE -g main -t halt, or with -g "<goal>" for other predicates.
2. Coding conventions: snake_case names, a comment above every predicate
giving its declarative reading ("foo(X, Y) is true when ...") and its
argument modes (+, -, ?), small helper predicates instead of long clauses.
3. The assignment's hard rules: the file contains only definitions, no
initialization directive, never call halt, no
assert/retract/b_setval/nb_setval, only library(lists), library(apply),
library(yall) and library(aggregate), and print nothing except what is asked.
4. How to run and test: one-line swipl commands, and plunit tests in a
separate file under tests/.
5. A self-review checklist you must go through before every answer.
6. Known failure modes of AI tools in Prolog, for example: negation (\+) on
unbound variables, using is/2 before variables are bound, writeq or print
adding quotes to atoms like 'AI' and 'c++', infinite left recursion,
duplicate solutions, leftover choice points, and cuts in the wrong place.
Also add a rule that you only do the one unit of work I ask for in each
message and never write a whole problem at once. Give me only the SKILL.md
content, in one code block.

## Prompt 4 (P1 facts and solution template)
I'm starting problem P1 (the department puzzle) from the PDF. First unit
only. In my file GROUPID_q1.pl I want the facts and the shape of a solution,
nothing else yet:
1. Facts listing the possible values of each attribute: dept/1, lang/1 and
project/1, using exactly the atoms the PDF gives (with 'c++' and 'AI'
quoted).
2. A predicate template(S) that gives a list of four p(Name, Dept, Lang,
Project) terms in the order 'Alex', 'Ben', 'Carla', 'Dana', with Dept, Lang
and Project left as unbound variables.
Explain in plain words why the names and 'AI' and 'c++' have to be quoted.
Don't write any clues or main yet.

## Prompt 5 (P1 fill with permutations)

binds every Dept, Lang and Project so that each value of each attribute is used exactly
once, giving every possible assignment on backtracking. Use permutation/2 from
